# Changelog

## [1.1.0] — 2026-11-01

**Chrome Edition** — redesigned entire site in a cinematic black/silver theme inspired by the reference video. New multi-section landing page, real WebGL metallic forms with SVG fallback, consistent dark calculator/admin/consumer experience, reworked Sign In, responsive navigation, scroll-reveal and reduced-motion behavior. Existing Java OOP engine, Firebase storage, Spring Security/CSRF and PDF billing retained. No data migration required.
