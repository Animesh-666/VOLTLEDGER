## Portfolio project description (copy-ready)

VOLTLEDGER is a full-stack Java electricity billing and energy analytics platform built with Java 21, Spring Boot, Spring Security, Thymeleaf, Firebase Cloud Firestore and PDFBox. It features object-oriented residential/commercial tariff calculations, a premium responsive dashboard, account-specific billing history, admin consumer management, PDF invoices, and usage analytics. I containerized the application with Docker and deployed it using Render and GitHub Actions CI.

## Feature highlights

1. **Java OOP:** classes, constructors, encapsulation, inheritance, polymorphism, and interfaces for billing strategies.
2. **Tariff accuracy:** progressive slab calculation and precise `BigDecimal` monetary rounding.
3. **Secure workflows:** separate admin/consumer access; backend ownership enforcement for invoices and PDFs.
4. **Cloud architecture:** Firestore storage behind Spring services and repository interfaces.
5. **Usability:** Clean Energy interface, responsive forms, visual analytics and searchable invoices.
6. **Release readiness:** Docker, GitHub Actions, configuration profiles and server-side secret handling.
