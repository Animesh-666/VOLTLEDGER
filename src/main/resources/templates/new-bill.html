HOW IT WORKS

More than a calculator.

Each saved invoice contains the original billing totals, consumption and line-by-line tariff breakdown.

01ValidateBean Validation checks user input.
02CalculatePolymorphic Java tariff strategy computes charges.
03ArchiveRepository saves consumer and invoice records using the active storage mode.
04ReviewAuthorized consumer can view the saved invoice.

Invoices are private: each invoice belongs to the selected registered consumer. To link an existing consumer to a different account, use Manage consumers first.
